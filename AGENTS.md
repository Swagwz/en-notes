# Agent instructions

Start with the project map in [agnets.md](./agnets.md), then read [agent/README.md](./agent/README.md) and only the topic documents relevant to the task.

Before changing behavior, check the current implementation and its migrations; documentation records decisions and status, but code and migrations are the source of truth when they disagree. Keep the docs updated when implementation status or product decisions change.

Do not treat dependencies' `node_modules/**/README.md` files as project documentation. The app-specific API entry at [apps/api/README.md](./apps/api/README.md) points to the canonical project docs.
